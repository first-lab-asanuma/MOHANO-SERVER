가용성·통화 알림
================

목적
----
통화 신청을 받을 가능성이 있는 사용자만 매칭 후보로 보여, 응답 없는 신청을 줄인다.

확정한 조건
------------
- 앱이 foreground 상태에서 45초 간격으로 heartbeat를 보낸다. 서버는 마지막 heartbeat가 90초
  이내면 온라인으로 판단한다.
- 오프라인 사용자도 통화 알림 수신에 동의했고 FCM/APNs token이 등록되어 있으면 후보가 될 수 있다.
- 둘 다 만족하지 않으면 후보 조회와 통화 신청 대상에서 제외한다.
- 알림 동의만 있고 token이 없거나, token만 있고 동의가 없으면 후보로 노출하지 않는다.

API
---
- `GET /v1/me/availability`
- `POST /v1/me/availability/heartbeat`
- `PUT /v1/me/availability`

구현 상태와 다음 작업
----------------------
- MySQL users에 `last_active_at`, `call_notifications_enabled`, `push_token`을 저장한다.
- 매칭 후보 조회와 통화 신청 생성 모두 같은 가용성 조건을 검사한다.
- Flutter 앱은 home 상태에서 foreground heartbeat를 전송한다.
- FCM/APNs 실제 발송, platform permission 요청, token 갱신/폐기는 Firebase 프로젝트와 iOS/Android
  provider 설정이 준비되는 다음 단계에서 연결한다. token은 로그·공개 API 응답에 포함하지 않는다.
